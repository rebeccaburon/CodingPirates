# CodingPirates

Dette repository indeholder sjove arkadespil fra [Vibe Arcade](https://github.com/asweigart/vibe_arcade), som er blevet tilpasset en smule, så børn kan prøve kræfter med **Python-programmering**. 

Spillene indeholder små opgaver på dansk, hvor børnene kan eksperimentere med variabler, tal, farver, hastighed og spilleregler.

**Målet er at lære Python gennem leg, kreativitet og eksperimenter!** 🚀



Spillene kan åbnes i **Thonny** og kræver `pygame-ce`.
